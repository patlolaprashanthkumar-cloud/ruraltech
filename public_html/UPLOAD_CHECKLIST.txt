TROUBLESHOOTING CHECKLIST:

If logo doesn't show:
☐  Verify rts.jpeg is in ROOT directory
☐  Check file name is exactly "rts.jpeg"
☐  Try clearing browser cache

If forms don't work:
☐  Check FormSubmit activation email
☐  Verify email address is correct
☐  Check internet connection
☐  Look for errors in browser console

If page looks broken:
☐  Verify ALL files uploaded to public_html
☐  Check styles.css is in same folder as index.html
☐  Clear browser cache and refresh
☐  Check file permissions (644)

☐  Verify thank-you.html is in public_html
☐  Check domain URL in forms is correct
☐  Make sure no typos in _next URLs
